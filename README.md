# maimai Random Pro

maimai Random Pro 是一个用于随机抽谱和管理 maimai 赛事的小工具。平时可以筛选难度、等级和定数来抽歌；举办比赛时，也可以用它导入选手、录入成绩、处理加赛，并把歌曲、排名和晋级结果同步到 OBS。

当前版本：**v3.6.0**。详细改动见 [更新日志](CHANGELOG.md)。

## 项目功能

- **随机抽谱**：按曲库、难度、谱面类型、等级或定数筛选，支持搜索和指定歌曲。可以排除歌曲，设置阶段内或整场赛事不重复抽取。
- **赛事管理**：导入表格或手动添加选手，设置比赛阶段、分组和晋级人数。支持逐曲录入完成率、DX 分，自动汇总并更新排名。
- **同分加赛**：晋级分界出现同分时单独录入加赛成绩，保留原成绩和每轮加赛记录。
- **赛事抽奖**：从赛事选手或手动名单中抽取中奖者，支持防重复中奖、逐个揭晓和中奖记录。
- **OBS 导播**：切换待机、歌曲、实时排名、晋级揭晓、抽奖和选手叫号画面，也可以设置倒计时、隐藏成绩。
- **手机控制**：手机与电脑连接同一局域网，扫码并输入配对码后即可操作，OBS 接收主机同步的展示内容。
- **数据保存**：提供自动快照、手动备份与恢复、操作日志，以及部分操作的撤销。赛后可以导出成绩表和结果图片。

界面使用液态玻璃样式，支持浅色和深色模式。抽谱卡片保留各难度的颜色，展示曲绘、等级、定数和歌曲资料；排名变化、重抽和结果揭晓都有对应的过渡动画。

## 使用方式

Windows x64 版为免安装 EXE，运行后会打开默认浏览器，不需要另外安装 Node.js。使用期间保持启动器开启。

打开网页后，顶部导航对应随机选曲、曲库、赛事、赛事抽奖和导播。比赛时先导入名单、设置阶段歌曲，再录入并保存成绩，核对排名后确认晋级。

在「导播」复制 OBS 展示地址，添加到 OBS 的浏览器来源，建议尺寸为 **1920 × 1080**。统一展示页面为 `/obs-live?clean=1`，由导播页切换场景。

手机控制也在「导播」连接：选择手机能访问的局域网地址，扫码打开后输入六位配对码。局域网访问需要电脑防火墙和路由器允许设备互通。

## 备份与升级

重要比赛请保留手动备份。升级前在旧版导出赛事备份，再到新版恢复；抽奖使用单独的备份。更换浏览器、设备或端口时，浏览器中的数据不会自动迁移。

Windows 版的主机存档位于 `%LOCALAPPDATA%\maimai-random-pro\state\session.json`，源码运行时默认位于项目的 `.state/session.json`。
