# maimai Random Pro v2.5

本地 maimai 抽谱与赛事工具。v2.5 重新设计真实 EXE 启动窗口，使用网站唱片 Logo、点阵背景、圆角玻璃面板、大标题与胶囊按钮；网站与启动器配色统一由 design/palette.json 生成。修复深浅主题选中按钮文字与背景同色、光球穿透导致内容对比度下降，以及启动器主题底色不一致。保留已有赛事、抽谱、表格导入和 OBS 功能。

Logo 预览与下载：`http://127.0.0.1:5174/logos`。四张原图均为 2172 × 724 透明 PNG，原图与生成提示词见 `logos-v1.3.zip`。

**本版已按用户要求打包为 Windows x64 免安装 EXE。** 启动器外观预览：`http://127.0.0.1:5174/launcher-preview`。运行文件位于 `release/`。具体改动见 `VERSION_NOTES.md`。启动器真实深色预览在 `release/launcher-dark.png`。

启动器固定使用深色模式，移除主题切换，网站仍支持深浅主题。网站玻璃面板底色调整为约 68%–70% 不透明度，保留至少 4.5:1 的正文对比度；两个 OBS 展示入口改为独立悬浮菜单，避免标题视差或内容滤镜遮挡。菜单支持边缘避让、滚动定位、Esc 和点击外部关闭。

## 使用 EXE

双击 `maimai-random-pro-2.5.0-win-x64.exe` 启动。程序内置 Node 运行环境，在默认浏览器打开界面；不需要安装 Node 或 npm。这是浏览器界面的免安装启动器，启动窗口提供打开页面、复制 OBS 地址；关闭窗口即可退出。首次启动解压运行文件，之后复用缓存。

适用 Windows 10 / 11 x64，需要系统自带的 .NET Framework 4.8 与现代浏览器。EXE 未作代码签名。运行缓存位于 `%LOCALAPPDATA%/maimai-random-pro/`；曲库、选手与设置保存在使用的浏览器中。退出启动窗口后，自行启动的本地服务会停止；浏览器中的保存数据继续保留。

默认网址是 `http://127.0.0.1:5174/`。若端口被占用，会尝试下一个端口，OBS 地址使用实际页面显示的地址。重复启动同一程序会打开已启动的页面。仅在本机提供服务。

## 从源码运行

使用 Node 24.19+ 与 pnpm 11.25。也可用 npm 安装依赖。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

完成构建后，也可以双击 `run.bat`；保持启动窗口开启。开发使用 `pnpm dev`。

## 抽谱

- 下拉菜单使用统一浮层，支持鼠标、键盘方向键、Enter、Esc 和长名单搜索。
- 难度按钮与结果卡片按 BASIC 绿、ADVANCED 黄、EXPERT 红、MASTER 紫、Re:MASTER 浅紫、UTAGE 粉显示，封面使用原图。
- 范围数字可直接输入，与滑条双向同步；输入范围超过另一端时会一同调整，最高限制为 15 / 15.0。空值或非数字输入不改变筛选，失去焦点后恢复有效值。
- **整数模式**：按显示等级筛选
- **小数模式**：按谱面真实定数筛选，步长 `0.1`，最大定数 **15.0**。
- JSON 定数支持 `levelValue`、`level_value`、`ds`。不会将整数或整数加号推算成真实定数。
- 抽取 1–4 张，也可搜索并指定谱面。候选列表分页显示，支持刷新后恢复筛选。

## 曲库与名单

曲库支持原 randomPlus JSON、UTF-8 BOM 与在线获取。在线曲库经本地服务访问 lxns

赛事支持 XLSX / XLS / CSV / TSV 导入昵称和 rating；兼容 `ranting` 表头。文件上限 10 MB，工作表最多 10,000 行和 100 列。可选择工作表和列映射，预览异常行后决定是否跳过。默认同名更新 rating，保留比赛成绩。默认五个晋级阶段；点击「自定义赛事」可设置阶段名称、预计参赛人数、歌曲数量、全局／分组排名、每组晋级、晋级目标和败者组。

「使用当前抽谱结果」将歌曲及曲绘写入当前阶段；「随机阶段歌曲」按抽谱页当前筛选生成赛制配置的歌曲数量。候选不足时只使用现有候选，不补充重复歌曲。

## OBS

主页面自动开启同步，保持主页面和启动窗口开启。点击「OBS 展示」查看连接状态并复制地址。在 OBS 添加浏览器来源，建议 1920 × 1080。

- 抽谱：`http://127.0.0.1:5174/obs?clean=1`
- 赛事：`http://127.0.0.1:5174/obs-tournament?clean=1`

如果实际服务端口不同，以界面复制的地址为准。正式来源无内容时保持透明；不带 `clean=1` 的预览显示等待或断线提示。同浏览器和独立 OBS 浏览器均通过本地服务同步。

## 主题与动效

右上角月亮 / 太阳按钮切换深色与浅色，记忆所选主题，首次启动采用系统偏好。主题以圆形过渡切换；不支持该浏览器功能时平滑切换颜色。

动效主要使用 CSS transform。

液态玻璃视觉参考 [rxing365/html-liquid-glass-effect-webgl](https://github.com/rxing365/html-liquid-glass-effect-webgl)，本地以独立实现的静态凸边法线图和 SVG 背景折射应用到全局界面。最多同时启用 6 个可见大面板，总面积限制 160 万 CSS 像素，单图不超过 384 × 256；不可见图释放，空闲时无折射渲染循环。小控件使用玻璃高光，移动设备、低核心设备和减少透明度模式自动降级。OBS 保持背景透明，排名板采用可读性更高的玻璃底色。

## 检查与打包

```sh
pnpm check
pnpm lint
pnpm test
pnpm dist:win
```

Windows 打包脚本使用系统 C# 编译器，将当前构建、Node、ws、曲库快照和许可证打成单个 EXE。构建机器需要 Node 和依赖，最终使用者无需安装。输出在 `release/`。

可使用 `--self-test --port=5188 --cache-dir=... --report=...` 检查 EXE 解压、内置运行环境和页面服务，而不打开浏览器。源码内提供 GitHub Actions Windows 构建工作流；网页与启动器外观验收通过后，手动运行工作流并勾选 `review_approved`，才会提供 EXE artifact。
